# 常用提示词

复制改一改就能用。生图时记得**把角色三视图一起附上**。

---

## 配图规划

```text
Use $dongcao-illustrations 先不要生图。
分析下面这篇内容哪里值得配图，输出 4 张左右的 shot list。
每张写清楚：放哪段后、主题、核心意思、结构类型、冬草在做什么、建议标注词。

<粘贴内容>
```

## 公众号长文配图

```text
Use $dongcao-illustrations 把下面这篇公众号推文生成 4 张正文配图。
16:9 横版，彩铅排线、米白纸底、深靛蓝线稿，三件识别物都要在。
每张单独生成，附角色三视图。

<粘贴内容>
```

## 公众号首图

```text
Use $dongcao-illustrations 为这篇《{标题}》生成一张首图。
3:4 竖版，冬草在做和标题相关的动作，画面安静，留白多，不要写标题文字。
```

## 小红书图文

```text
Use $dongcao-illustrations 为「{主题}」生成 3 张小红书配图。
3:4 竖版，一张一个动作，连起来是一个小故事。
```

## 朋友圈单图

```text
Use $dongcao-illustrations 为「{今天发生的事}」生成一张朋友圈配图。
1:1 方图，就一个瞬间，不要标注文字。
```

## 步骤图

```text
Use $dongcao-illustrations 把「{怎么挑 / 怎么存 / 怎么泡}」画成一张分格图。
3-4 格，每格一个动作，格子用手绘细线随意框，不要画成表格。
```

## 前后对比

```text
Use $dongcao-illustrations 画一张「{A} 和 {B}」的对比图。
左右两半，不要画箭头，用两个动作的差别说话。
```

## 物件特写

```text
Use $dongcao-illustrations 为「{这件东西}」生成一张特写图。
物件占主体，冬草的手从画面边上伸进来拿着它。
```

## 修图

### 变成平涂了

```text
Use $dongcao-illustrations 这张图变成平涂了。
保持构图和颜色不变，只把每块颜色改回看得见的彩铅斜排线，线稿换成深靛蓝，去掉渐变和投影。
```

### 脸不对

```text
Use $dongcao-illustrations 这张图的脸和三视图对不上，只改脸：
黑点眼无眼白无高光、细短眉、小弧线嘴、两坨橘粉腮红。其他一律不动。
```

### 冬草在旁观

```text
Use $dongcao-illustrations 冬草只是站在旁边，让她真的动手做这件事，
手要在物件上，姿势要看得出在用力或在专注。风格和三件识别物保持不变。
```

### 画面太满

```text
Use $dongcao-illustrations 这张太满了，物件只留 1-2 个，其余留白。
```

### 去掉多余文字

```text
Use $dongcao-illustrations 去掉图里的「{文字}」，那块补成一样的米白纸底，其他全部不动。
```
