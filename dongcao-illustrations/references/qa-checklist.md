# QA Checklist

生成后逐条对。意思和媒介那两组不过，直接重做，不用看别的。

## 意思（一票否决）

- 她在**过自己的日子**，不是在给读者做示范。
- 把所有文字标注去掉，这张图还成立。
- 画面没有在向读者说话：没有对比、没有步骤号、没有打叉、没有「正确 / 错误」。
- 读者看了会觉得「她的生活是这样」，不是「哦，原来要这样做」。
- 画面里没有剂量、温度、时长、根数这类参数。

## 媒介（一票否决）

- 看得见彩色铅笔的排线笔痕，**细密、多层、方向一致**，不是粗糙涂抹。
- **纸的颗粒从颜色里透出来**，颜色没有把纸盖死。
- 颜色是压过层的沉色，不发艳、不发荧光。
- 底和用途对得上：单独发的是**米白纸底带颗粒**；要嵌进别的版面的是**纯透明**，没有白、没有米白、没有纸纹。
- 米白底那一档**不是纯白**；透明底那一档除了脚下那点影子，背景一点残留都没有。
- 线稿是深靛蓝色，**不是黑色**。
- 没有任何一块是平涂的，也不能像蜡笔或马克笔。
- 没有渐变、没有高光、没有投影、没有塑料光泽。
- 脚下只有一小片浅蓝铅笔乱线，没有画形状的影子。

## 角色

- 冬草在画面里，而且在做事。
- 脸和 `assets/reference/` 三视图对得上：黑点眼、无眼白、细短眉、小弧线嘴、两坨橘粉腮红。
- 比例是 4.5 头身 Q 版，不是成年写实身材。
- 头发是深靛蓝黑，正面两条辫、背面一条粗辫。
- **三件识别物都在**：红珊瑚项链 / 雪山纹银腰牌 / 冬草日记本。
- 藏袍是宝蓝，暗纹是草芽不是花。
- 裙子是竖条纹，不是横条。

## 画面

- 一张图只讲一个瞬间。
- **一张图里只有一个冬草。**
- 主体占画面 45%-65%。
- 至少 30% 是干净的纸。
- 颜色没超出七色板。
- 中文标注默认 0 处；有的话最多 4 处、每处 2-8 字，**必须是铅笔手写体**。
- 没有复刻 `assets/examples/` 里的旧构图。
- 光是平的，情绪是安静的。

## 失败信号

出现以下情况，重生成或局部编辑：

- **画面在讲课**：前后对比、步骤编号、打叉的错误示范、举着标牌。
- **文字是打印字体**，不是铅笔手写。
- **画面里出现两个冬草**，变成漫画分镜。
- **底部有大号标语**，变成海报。
- 出现漫画情绪符号：感叹线、汗滴、星星眼、心形。
- 张嘴的夸张表情，不是那个固定的小弧线微笑。
- 笔触粗糙跳色，像蜡笔或马克笔，纸被盖死。
- 颜色饱和度拉满，玫红青绿发荧光。
- 颜色平涂，像矢量插画或扁平设计。
- 线变成黑色，整张图发冷发硬。
- 该米白的底做成了纯白，纸感没了；或者该透明的底带着一层米白，嵌进版面后露出方块边。
- 画风滑向动漫、日系、二次元、3D、盲盒、手办。
- 脸变成大眼睛加高光，或者变成写实美女。
- 日记本不见了，或者封面字画错。
- 冬草只是站着笑，没有在做事。
- 画面堆满了元素，没有留白。
- 出现雪山＋经幡＋牦牛＋转经筒全堆在一起的"民族风套餐"。
- 颜色饱和度拉满，刺眼。
- 出现边框、标题栏、水印、logo。

## 迭代方法

| 问题 | 怎么改 |
| --- | --- |
| 在讲课 | 回到 `composition-patterns.md` 第一类，换成她的一个日常时刻重画 |
| 笔触粗、颜色艳 | 强调 fine dense layered hatching, paper grain showing through, muted |
| 打印字体 | 强调 all text hand-written in pencil；或干脆去掉文字 |
| 一图两人 | 强调 exactly one 冬草 in the image |
| 该透明却带底 | 用 `prompt-template.md` 的「把米白底改成透明底」编辑提示 |
| 像平涂矢量 | 用 `prompt-template.md` 的「修媒介」编辑提示 |
| 线太黑太硬 | 强调 deep indigo blue pencil outlines, never black |
| 太像动漫 | 强调 children's-book, chibi, plain black dot eyes, no catchlights |
| 脸不对 | 附三视图，用「修脸」编辑提示 |
| 冬草在旁观 | 用「让动作更实」编辑提示 |
| 画面太满 | 删物件，只留 1-2 个，扩大留白 |
| 太民族风套餐 | 去掉经幡和转经筒，只留草甸和一个物件 |
| 颜色刺眼 | 限死七色板，降低饱和，多留纸底 |
| 字写错 | 先局部编辑；错得多就减少标注数量重生成 |

## 交付判断

一张合格的图，第一眼应该像**一页手绘绘本里的某一天**，不是像一张 AI 插画，更不是一张说明图。

两个最常见的失败，按顺序查：

1. 第一眼觉得"这是在教我做事"——意思垮了，回 `composition-patterns.md` 第一类重想。
2. 第一眼觉得"这是 AI 画的"——媒介垮了，回去看排线密度和纸底有没有透出来。
