# QA Checklist

生成后逐条对。媒介那几条不过，直接重做，不用看别的。

## 媒介（一票否决）

- 看得见彩色铅笔的排线笔痕，颜色是一层层排出来的。
- 底是米白纸，有颗粒，**不是纯白**。
- 线稿是深靛蓝色，**不是黑色**。
- 没有任何一块是平涂的。
- 没有渐变、没有高光、没有投影、没有塑料光泽。
- 脚下只有一小片浅蓝铅笔乱线，没有画形状的影子。

## 角色

- 冬草在画面里，而且在做事。
- 脸和 `assets/reference/` 三视图对得上：黑点眼、无眼白、细短眉、小弧线嘴、两坨橘粉腮红。
- 比例是 4.5 头身 Q 版，不是成年写实身材。
- 头发是深靛蓝黑，正面两条辫、背面一条粗辫。
- **三件识别物都在**：红珊瑚项链 / 雪山纹银腰牌 / 冬草日记本。
- 藏袍是宝蓝，暗纹是草芽不是花。
- 裙子是竖条纹，不是横条。

## 画面

- 一张图只讲一个瞬间。
- 主体占画面 45%-65%。
- 至少 30% 是干净的纸。
- 颜色没超出七色板。
- 中文标注 0-4 处，每处 2-8 字，能读。
- 没有复刻 `assets/examples/` 里的旧构图。
- 光是平的，情绪是安静的。

## 失败信号

出现以下情况，重生成或局部编辑：

- 颜色平涂，像矢量插画或扁平设计。
- 线变成黑色，整张图发冷发硬。
- 背景是纯白，纸感没了。
- 画风滑向动漫、日系、二次元、3D、盲盒、手办。
- 脸变成大眼睛加高光，或者变成写实美女。
- 日记本不见了，或者封面字画错。
- 冬草只是站着笑，没有在做事。
- 画面堆满了元素，没有留白。
- 出现雪山＋经幡＋牦牛＋转经筒全堆在一起的"民族风套餐"。
- 颜色饱和度拉满，刺眼。
- 出现边框、标题栏、水印、logo。

## 迭代方法

| 问题 | 怎么改 |
| --- | --- |
| 像平涂矢量 | 用 `prompt-template.md` 的「修媒介」编辑提示 |
| 线太黑太硬 | 强调 deep indigo blue pencil outlines, never black |
| 太像动漫 | 强调 children's-book, chibi, plain black dot eyes, no catchlights |
| 脸不对 | 附三视图，用「修脸」编辑提示 |
| 冬草在旁观 | 用「让动作更实」编辑提示 |
| 画面太满 | 删物件，只留 1-2 个，扩大留白 |
| 太民族风套餐 | 去掉经幡和转经筒，只留草甸和一个物件 |
| 颜色刺眼 | 限死七色板，降低饱和，多留纸底 |
| 字写错 | 先局部编辑；错得多就减少标注数量重生成 |

## 交付判断

一张合格的图，第一眼应该像**一页手绘的绘本**，不是像一张 AI 插画。

如果第一眼就觉得"这是 AI 画的"，八成是媒介垮了——回去看排线和纸底。
