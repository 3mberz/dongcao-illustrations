# 冬草 IP

## 角色定义

冬草是《冬草日记》的固定视觉 IP，一个那曲的藏族女孩。

她不是吉祥物，不是贴纸，不是可爱装饰。她是这些内容里真正在高原上生活和做事的那个人——挖草、晒草、筛草、装袋、寄货、跟人说话、晚上写日记。

默认每张图都要出现冬草。如果画面里没有她，必须有她的日记本或她刚放下的东西，让人知道她在场。

## 基准

`assets/reference/` 里的角色三视图是唯一权威依据。脸、比例、配色、配件出现不一致时，一律以三视图为准，不以过往生成图为准。

## 比例

- Q 版，约 4.5 头身：头大、身体短、四肢短而圆。
- 圆脸，脸颊饱满。
- 手脚画成圆钝的小形状，不画手指关节。

## 五官

- **纯黑椭圆点眼**，没有眼白，没有高光。
- 眉毛细、短、深色。
- 嘴是一条小小的上弯弧线。
- 鼻子几乎不画，最多一个极小的点。
- **两坨橘粉色圆腮红**，位置在眼睛正下方偏外。

## 头发

- 深靛蓝黑色，用铅笔细线排出一根根发丝的方向。
- 正面：两条辫子垂在胸前左右两侧。
- 背面：一条粗麻花辫垂到腰。
- 辫子上串小颗红珊瑚珠和绿松石珠。
- 额前有几缕碎发。

## 三件识别物（每张图都要在）

1. **红珊瑚大圆珠项链**——橘红色，颗粒饱满，绕颈一圈垂到胸前。
2. **银色錾花腰带牌**——中心是雪山纹样，嵌一颗红珊瑚。
3. **《冬草日记》本子**——棕色皮封面，封面上是简单的三角雪山线条和「冬草日记」四个字，铜扣带，用带子挂在腰侧。

第 3 件是这个 IP 的核心符号。判断标准：如果把日记本去掉，这张图就认不出是冬草了——那说明其他识别点画得不够，但日记本本身永远不能省。

## 服装

- 内层：宝蓝色藏袍上衣，暗纹是**小草芽图案**，不是花卉。
- 外层：彩色**竖条纹**长裙，条纹宽窄不一。
- 胸前：斜披一条红橙黄几何锯齿纹织锦。
- 脚上：深棕色圆头藏靴。
- 次要配件：绿松石加红珊瑚的长耳坠，腰侧几个小银饰垂链。

## 性格

- 安静、温和、话不多。
- 手上总在做事，做得认真。
- 不表演、不卖萌、不摆拍。
- 高兴是浅浅的高兴，累是安静的累。

## 常见动作

让冬草承担画面的核心动作：

- 蹲在草甸上挖草，手里捏着一根。
- 举起一根草对着光看。
- 蹲着用竹筛筛草，灰往下落。
- 把草一根根码进木盒。
- 蹲在炉子边烧水，铜壶冒气。
- 背着草篓走在坡上。
- 把布袋口扎紧，贴上标。
- 坐在灯下翻开日记本写字。
- 抬头看天，看雪山，看要来的雨。
- 蹲在牦牛旁边，手搭在牛背上。

## 禁止

- 不要画成动漫少女、日系角色、二次元。
- 不要画成 3D、手办、盲盒风。
- 不要给她夸张的大眼睛、星星眼、高光眼。
- 不要卖萌姿势：比耶、歪头杀、飞吻、爱心手。
- 不要让她只是站着微笑当封面模特。
- 不要改她的服装配色和三件识别物。
- 不要把她画成成年写实美女——她是 Q 版绘本角色。
- 不要画成苦情、可怜、卖惨的样子。

## 判断标准

如果把冬草从画面里去掉，这张图想说的事还完全成立，说明她太装饰了。

重写提示词，让她成为动作主体。
