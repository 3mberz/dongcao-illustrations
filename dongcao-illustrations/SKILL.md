# 冬草日记 彩铅正文配图

## 核心定位

**把高原的日常，画成一个温暖的瞬间。**

这是这个 IP 的魂，写在角色三视图上，所有判断都从这句话往下推。

默认视觉 IP 是「冬草」：那曲的藏族女孩，深靛蓝辫子、彩色竖条纹裙、红珊瑚项链，腰上永远挂着那本《冬草日记》。

她是一个**过日子的人**，不是一个讲课的人。

### 最容易犯的错

**把配图做成信息载体。**

给一篇讲吃法、讲保存、讲怎么挑的文章配图时，最自然的反应是把知识点画出来——前后对比、步骤分格、打叉的警示牌、标上剂量和温度。

这么做，冬草就从一个人变成了举着标牌的演示员。画面在向读者说话，而不是在过日子。魂就没了。

**配图不承担信息传递。信息归正文。**

正文已经把吃法、剂量、禁忌说清楚了。配图的任务是让人愿意读下去、愿意相信这个人。文章功能性已经很强，配图再功能性，整篇就是一份说明书，没有人味。

判断标准：

- 这张图里她是在**过自己的日子**，还是在**给读者做示范**？后者就错了。
- 把所有文字标注去掉，这张图还成立吗？不成立说明它在靠文字讲课。
- 读者看了会觉得「她的生活是这样」，还是「哦，原来要这样做」？要前者。

### 两个识别点

1. **彩色铅笔的排线笔触**——细密、多层、方向一致，纸的颗粒要从颜色里透出来。一旦变成平涂、蜡笔涂抹或高饱和马克笔，风格立刻垮。
2. **腰间那本冬草日记**——IP 的固定符号。哪怕只画一个背影、一只手，这本日记在，就认得出是谁。

## 工作流

### 1. 消化内容

先读用户给的正文、链接、Markdown、截图或主题。提炼：

- 这段内容背后，冬草的日子是什么样的
- 文章在讲的这件事，她自己平时是怎么做的
- 读者在哪一句会停下来

**不要去找"哪个知识点需要画出来"。** 要找的是"这段话对应她的哪个日常时刻"。

举例——文章在讲「秋天两种吃法：焖泡和清炖」：

- 错的找法：画一张四格教程，标上 80 度、1-2 根、小火 1 小时。
- 对的找法：画她的一顿清晨——桌上一杯焖着的虫草茶冒着气，旁边砂锅刚揭盖，她低头在闻。两种吃法都在画面里，但它是一顿早饭，不是流程图。

信息（度数、根数、时长、禁忌）一个字都不要进画面，全部留给正文。

不要平均配图。一篇文章能有一两张真正安静的好图，胜过五张说明图。

### 2. 先出配图策略

如果用户只是说「分析怎么配图 / 看看哪里需要图」，先给 shot list，不要直接生图。每张写清楚：

- 放在哪一段后面
- 图的主题
- 核心意思
- 结构类型
- **这是她的哪个日常时刻**
- 冬草正在做什么（为她自己做，不是做给读者看）
- 建议元素
- 建议中文标注词——**默认没有**，非写不可才写

默认 3-6 张。短内容 1-2 张；长文也不要超过 8 张。够用就好。

出 shot list 时逐张自检：这张是她在过日子，还是在做示范？只要出现"对比""步骤""正确做法/错误做法""打叉"这类念头，停下来重想。

### 3. 单张生成

如果用户明确说「生成 / 出图 / 做图 / 帮我画」，不要停下来等确认。每张单独生成，不要把多张拼在一张里。

每张图只画一个瞬间。提示词必须包含：

- 彩色铅笔排线笔触、米白纸底、纸张颗粒
- **深靛蓝色铅笔线稿，不是黑色**
- 冬草的固定外形和三件识别物（珊瑚项链 / 雪山纹银腰牌 / 冬草日记本）
- 七色色板
- 冬草承担核心动作
- **一张图只出现一个冬草**
- 所有文字必须是铅笔手写体，禁止打印字体
- 禁止平涂、渐变、矢量、3D、动漫脸、写实照片感、漫画情绪符号

### 4. 检查与迭代

生成后对照 `references/qa-checklist.md`。出现以下问题，优先重生成或局部编辑：

- **画面在讲课，不是在过日子**
- 颜色变成平涂或蜡笔涂抹，看不见细密的铅笔排线
- 纸的颗粒被颜色盖死，颜色发艳
- 线稿变黑色
- 背景变纯白
- 出现打印字体
- 一张图里出现两个冬草
- 日记本没画或画错
- 脸和三视图对不上
- 画风滑向动漫、3D、写实或矢量插画
- 画面太满，没有留白的纸

### 5. 保存交付

如果用户在 workspace 内工作，把最终图放到：

```text
assets/<文章名>-配图/
```

按顺序命名：

```text
01-主题名.png
02-主题名.png
```

保留原始生成文件，不要覆盖已有资产，除非用户明确要求替换。

## 输出口径

生成前的策略要短而准。生成后的交付说清楚：

- 生成了几张
- 每张的用途和放置位置
- 保存路径
- 哪几张最稳，哪几张是可选的

不要长篇解释风格理论。让图自己说话。
