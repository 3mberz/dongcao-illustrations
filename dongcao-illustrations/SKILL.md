# 冬草日记 彩铅正文配图

## 核心定位

把一段中文内容里的场景、动作、判断或心情，画成一张有纸感、有笔触、温暖安静的绘本式插图。

不是商业插画，不是 PPT 信息图，也不是冷淡的极简线稿。

默认视觉 IP 是「冬草」：那曲的藏族女孩，深靛蓝辫子、彩色竖条纹裙、红珊瑚项链，腰上永远挂着那本《冬草日记》。冬草必须是画面里正在做事的那个人，不能只是站在旁边当装饰。

这套风格的识别点有两个，缺一个就不成立：

1. **彩色铅笔的排线笔触**——每一块颜色都是铅笔斜着一层层排出来的，能看见笔道和纸的颗粒。一旦变成平涂或渐变，风格立刻垮。
2. **腰间那本冬草日记**——这是 IP 的固定符号。哪怕只画一个背影、一只手，这本日记在，就认得出是谁。

## 先读这些参考

按任务需要读取，不要一次塞满上下文：

- `references/style-dna.md`：媒介、色板、笔触、禁忌。**每次生图前必读。**
- `references/dongcao-ip.md`：冬草的外形、比例、固定配件、性格和禁忌。
- `references/composition-patterns.md`：画面结构类型、原创场景方法、反复刻规则。
- `references/prompt-template.md`：单张生图提示词模板。
- `references/qa-checklist.md`：生成后检查和迭代规则。
- `assets/reference/`：角色三视图基准。**这是唯一权威的形象依据**，脸、比例、配色不一致时以它为准。

## 工作流

### 1. 消化内容

先读用户给的正文、链接、Markdown、截图或主题。提炼：

- 这段内容在讲什么事
- 哪几处是有画面的——有动作、有场景、有人、有物
- 哪几处是纯道理，不适合配图
- 读者在哪一句会停下来

不要平均配图。优先挑**有身体动作的瞬间**：蹲下来挖、举起来看、蹲在地上筛、把袋子封上、抬头看天、坐在灯下写。抽象判断也要落到一个具体动作上再画。

### 2. 先出配图策略

如果用户只是说「分析怎么配图 / 看看哪里需要图」，先给 shot list，不要直接生图。每张写清楚：

- 放在哪一段后面
- 图的主题
- 核心意思
- 结构类型
- **冬草在画面里正在做什么**
- 建议元素
- 建议中文标注词（可以没有）

默认 3-6 张。短内容 1-2 张；长文也不要超过 8 张。够用就好。

### 3. 单张生成

如果用户明确说「生成 / 出图 / 做图 / 帮我画」，不要停下来等确认。每张单独生成，不要把多张拼在一张里。

每张图只画一个瞬间。提示词必须包含：

- 彩色铅笔排线笔触、米白纸底、纸张颗粒
- **深靛蓝色铅笔线稿，不是黑色**
- 冬草的固定外形和三件识别物（珊瑚项链 / 雪山纹银腰牌 / 冬草日记本）
- 七色色板
- 冬草承担核心动作
- 禁止平涂、渐变、矢量、3D、动漫脸、写实照片感

### 4. 检查与迭代

生成后对照 `references/qa-checklist.md`。出现以下问题，优先重生成或局部编辑：

- 颜色变成平涂，看不见铅笔排线
- 线稿变黑色
- 背景变纯白
- 日记本没画或画错
- 脸和三视图对不上
- 画风滑向动漫、3D、写实或矢量插画
- 画面太满，没有留白的纸

### 5. 保存交付

如果用户在 workspace 内工作，把最终图放到：

```text
assets/<文章名>-配图/
```

按顺序命名：

```text
01-主题名.png
02-主题名.png
```

保留原始生成文件，不要覆盖已有资产，除非用户明确要求替换。

## 输出口径

生成前的策略要短而准。生成后的交付说清楚：

- 生成了几张
- 每张的用途和放置位置
- 保存路径
- 哪几张最稳，哪几张是可选的

不要长篇解释风格理论。让图自己说话。
